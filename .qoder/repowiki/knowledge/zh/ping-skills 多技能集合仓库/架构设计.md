本仓库不包含可运行应用，而是以目录为单位的独立 Skill 集合：每个子模块提供 SKILL.md（触发与流程）、references/protocol/（规则与 JSON Schema）、scripts/（Python 驱动）和 tests/（pytest）。根级 install.sh 将选定 skill 复制到目标项目的 .claude/.qwen/.qoder/.opencode/skills 及 agents 目录，并剥离测试与 frontmatter tools 行。两个单元测试类 Skill（java-unit-test-generator 与 batch-unit-test-generator）共享同一套 NEXT_STEP 协议与 jaut 引擎脚本，但各自维护一份已分叉的副本；sensitive-log-review 走子扫描器流水线并以 CI 退出码对外契约；sensors-analyze 走 LLM+Python 混合管线输出 sensors.csv。所有 Skill 均遵循 Python stdlib-only 脚本约定，并通过各自的 conftest.py 将 scripts/ 加入 sys.path 以便单测调用。
