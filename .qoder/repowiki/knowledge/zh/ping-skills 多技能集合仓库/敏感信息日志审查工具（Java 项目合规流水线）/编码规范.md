- 每个子脚本遵循统一的 CLI 契约：通过 `argparse` 解析参数，使用 `common.paths.get_output_dir` 获取输出目录，通过 `FailureRecorder` 记录失败文件并在末尾 `flush()` 写入分片，stdout 末尾输出 `SUMMARY: key=value ...` 供 main 解析计数。
- 所有文件 I/O 统一使用 `encoding='utf-8', errors='replace'` 解码，确保含乱码字节时以占位符显示而非静默丢弃，避免漏扫敏感日志。
- 规则与词典文件集中管理于 `rules/` 与 `dictionary/` 目录，通过 `common/pojo_config.py` 与 `common/dictionary.py` 唯一加载，禁止在业务脚本中硬编码路径或正则。
- 对外部命令（git/java/checkstyle）的调用统一经 `common/git_utils.resolve_repo`、`validate_ref` 等封装函数处理，并对返回值进行非零退出码检查后转为结构化错误提示。
- HTML 报告渲染时对全部用户输入使用 `html.escape` 转义，长列表采用 `<pre>` 预览加 `<details>` 折叠展开，失败文件区块单独展示。
- 词典维护遵循四层优先级（whitelist > blacklist > core > extended）与版本头规范（文件头部 `# version: YYYY-MM-DD.N` 每次修改递增），新增词条按语义归属对应层级文件。
