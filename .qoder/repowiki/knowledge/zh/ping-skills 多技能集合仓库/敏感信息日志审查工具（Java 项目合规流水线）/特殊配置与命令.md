运行入口为 `python scripts/main.py -r <git-repo>`，默认对比 `master` 分支仅扫描变更 Java 文件；支持 `--full-scan` 全量扫描、`--output-dir`/`SLR_OUTPUT_DIR` 指定产物目录、`--run-id` 在 CI 中做并行隔离、`--fail-on violation,sensitive` 控制门禁项、`--doctor` 环境诊断模式、`--strict-mode` 严格模式（failedFiles>0 即退出码 2）；需在 Windows 设置 `PYTHONIOENCODING=utf-8` 避免中文乱码。
