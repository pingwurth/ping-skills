模块以 `scripts/jaut/` 为核心 Python 包，严格遵循 `__init__.py` 中声明的单向分层依赖：L0(config/models/logutil/protocol) → L1(proc/state/gitops) → L2(jacoco/surefire/javasrc/maven/worktree) → L3(rules/prompt/decisions) → L4(transitions/cli) → L5(顶层 scripts/*.py 入口)。每个入口脚本（如 `batch_init.py`、`batch_next.py`）仅实现 `add_arguments(parser)` 与 `handler(args) -> (Decision, EmitContext)`，统一由 `cli.run_cli` 完成参数解析、日志初始化、异常到 `StepError` 的转换、路由到 `transitions.build_next_step` 以及通过 `protocol.emit` 输出标准协议块；stdout 仅承载协议负载，过程日志落盘。决策产物 `Decision`（含 Route、NextCommand、ResumeOption 等）在 `models.py` 中以 dataclass 表达，`transitions.py` 集中将 Route 映射为具体 next_step（run_script/write_code/finish/ask_user），避免各脚本硬编码脚本路径。状态持久化通过 `state.StateStore` 写入每类的 `state.json`，批量计划汇总为 `batch_state.json`，两者均提供 `from_dict/to_dict` 向后兼容旧 schema。协议层 `protocol.py` + `protocol/*.schema.json` 定义 `:::NEXT_STEP_BEGIN/END:::` 标记的 JSON 负载，所有脚本必须遵守该契约。外部工具链（mvn、git、JaCoCo、Surefire）封装在 L2 模块中，L3 决策函数保持纯函数无 I/O，便于单测覆盖。
