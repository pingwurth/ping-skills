- 入口脚本统一实现 `add_arguments(parser)` 与 `handler(args) -> (Decision, EmitContext)`，并由 `cli.run_cli` 包装参数解析、日志与协议输出，禁止自行处理 argparse。
- 错误通过 `StepError.state_error` / `StepError.exec_error` 抛出，携带完整 `Decision`，由 `run_cli` 统一转为 failed 协议块与对应 exit code（3/2）。
- 所有常量（阈值、超时、协议枚举、退出码、路径模板）集中在 `config.py`，业务模块只读引用，禁止散落字面量。
- 领域模型使用 dataclass 并提供 `to_dict` / `from_dict` 成对方法，`from_dict` 对缺失键返回默认值以兼容旧 `state.json`。
- next_step 的 run_script 路由目标与参数由 `transitions._ROUTE_SCRIPT` 与 `_params_for` 集中解析，脚本内不拼接相对路径或硬编码 SCRIPTS_DIR。
- stdout 仅输出被 `:::NEXT_STEP_BEGIN:::` / `:::NEXT_STEP_END:::` 包裹的协议 JSON 块，所有调试与过程信息一律写入 `logs/` 下的日志文件。
