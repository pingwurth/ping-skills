- 每个 Skill 自包含 SKILL.md（含 name/description 前缀）、references/、protocol/、scripts/ 与 tests/，不依赖仓库内其他 Skill。
- 脚本仅使用 Python 标准库，跨平台且支持 --help；共享逻辑放入 scripts/common/。
- 单元测试统一使用 pytest，文件名 test_<subject>.py，用例命名 test_<behavior>，并在 tests/conftest.py 中把对应 scripts/ 加入 sys.path。
- 单元测试类 Skill 通过 stdout 末尾的 :::NEXT_STEP_BEGIN:::/:::NEXT_STEP_END::: JSON 块与 LLM 协作，exit code 0=完成、1=继续、2=脚本错误、3=状态/协议错误。
- Skill 文档（SKILL.md / references/ / README）是用户契约，需与脚本 flags、exit codes、协议字段保持同步。
