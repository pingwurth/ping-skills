- 每个脚本以 `main() -> int` 形式组织，统一通过 `argparse` 解析参数，并在 `finally` 块中调用 `utils.next_step()` 输出下一步指令。
- 日志统一通过 `utils.setup_logging(name, log_path)` 初始化，所有调试信息写入文件，stderr 被重定向至日志文件，仅 `next_step` 向 stdout 输出。
- 脚本间通过固定文件名契约传递中间产物：`sensors.json` → `entry.txt` → `call_sites.json` → `sensors.csv` → `check_report.txt` / `review_report.txt` / `diff_report.txt`。
- CSV 表头固定为 `page_name,first_biz_id,second_biz_id,first_biz_name,second_biz_name,event,file[,illegal_reason]`，各脚本在读写时严格遵循该顺序与列名。
- 文本搜索优先尝试 ripgrep（`which rg`），失败时回退到纯 Python 遍历文件并使用 `re.finditer` 匹配，保持跨环境一致性。
- 调用点范围通过花括号/圆括号平衡算法计算起止行，避免依赖 AST 解析，从而兼容 JS/TS/Vue/Java/Swift/Go/Dart 等多语言片段。
