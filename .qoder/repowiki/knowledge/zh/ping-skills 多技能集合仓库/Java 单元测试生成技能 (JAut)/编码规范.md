- 所有脚本通过 `cli.run_cli` 统一处理 argparse、logger 初始化、异常到 `failed` 协议块的转换与退出码输出，入口只需提供 `add_arguments` 与 `handler`。
- 决策逻辑集中在 `decisions.py` 的纯函数中，不直接访问文件系统或执行外部命令，副作用通过 `Decision.mark_done/reset_trajectory` 等标志回传给入口脚本落地。
- 状态文件 `state.json` 必须通过 `StateStore.save` 原子写入（临时文件 + os.replace + fsync），并发读写通过 `.lock` 文件加独占锁保护。
- 脚本间通信唯一契约是 stdout 末尾的 NEXT_STEP 协议块（`:::NEXT_STEP_BEGIN:::` / `:::NEXT_STEP_END:::`），过程日志一律写入 `<workdir>/logs/<script>.log`。
- 配置常量集中于 `config.py`，阈值、超时、枚举值均以只读形式被其他模块引用，禁止散落字面量。
- 模型字段采用 dataclass + `to_dict/from_dict` 成对实现，并兼容旧 schema 缺失键，保证 `state.json` 向后兼容。
