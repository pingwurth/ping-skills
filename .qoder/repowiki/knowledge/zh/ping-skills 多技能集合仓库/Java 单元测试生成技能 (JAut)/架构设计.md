模块以 `scripts/jaut/` 为核心 Python 包，按 `__init__.py` 声明的单向分层组织：L0(config/models/logutil/protocol) → L1(proc/state/gitops) → L2(jacoco/surefire/javasrc/maven/worktree) → L3(rules/prompt/decisions) → L4(transitions/cli) → L5(顶层 scripts/*.py 入口)。入口脚本（select_worktree/init_coverage/make_plan/build_prompt/validate_rules/verify_coverage）统一通过 `cli.run_cli` 解析参数、执行 handler、将 `Decision` 经 `transitions.build_next_step` 路由为 `next_step`，再由 `protocol.emit` 输出带 `:::NEXT_STEP_BEGIN/END:::` 标记的 JSON 协议块；退出码遵循 0/1/2/3 契约。状态持久化由 `state.StateStore` 提供原子写入（临时文件 + os.replace + fsync）与跨进程文件锁，支持 schema_version 迁移管道实现断点续跑。决策核心 `decisions.py` 为纯函数层，零 I/O，仅依据 `models` 中的类型化上下文计算下一步路由，所有副作用（写 state、运行 mvn、解析报告）集中在上层入口脚本。协议定义在 `protocol/*.schema.json`，规则文档在 `references/`，测试覆盖全部子模块位于 `tests/`。
