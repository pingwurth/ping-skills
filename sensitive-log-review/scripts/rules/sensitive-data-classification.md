# 银行金融业大而全的敏感数据分类分级清单

> 本清单供**步骤7b LLM 语义复核**使用：AI 分析器读取变更 POJO 全文后，对照本清单判断字段（含注释语义）是否属于敏感数据。
> 机器可执行的精简正则规则见同目录 `sensitive-field-rules.json`（步骤7a 规则初筛层使用）。

## 一、 个人客户敏感数据（C端）
*依据 JR/T 0171-2020，此类数据多为 C3（最高敏感）或 C2（高敏感）级别，泄露易导致人身/财产安全受损或人格尊严受侵害。*

| 数据子类 | 典型敏感数据项示例 | 敏感级别参考 |
| :--- | :--- | :---: |
| **身份鉴别信息** | 账户登录密码、支付密码、交易密码、查询密码；银行卡CVN/CVN2、有效期；短信验证码、动态口令(OTP)；USBKey/U盾信息、个人数字证书、密码提示问题答案。 | **C3** |
| **生物识别信息** | 人脸、指纹、声纹、虹膜、掌纹、基因等生物特征的**原始图像/样本**及**特征值/模板**。 | **C3** |
| **金融账户信息** | 银行卡号、支付账号、证券/基金/保险/公积金账户；银行卡磁道数据/芯片等效信息；账户余额、开户机构、基于上述信息生成的支付标记(Token)。 | **C3/C2** |
| **财产与信用信息** | 个人银行流水、征信报告、信贷记录、逾期/欠款信息、担保情况；个人收入证明、房产信息、车辆信息、纳税额、大额资产持有情况。 | **C2/C3** |
| **交易与行为信息** | 交易订单号、交易金额、支付/透支记录、交易日志；证券委托/成交/持仓明细；保单信息及理赔记录；大额资金划转指令。 | **C2** |
| **基本资料与行踪** | 身份证号、护照号、军官证号；精确家庭住址；实时精准定位信息、GPS车辆轨迹、出入境记录、精确住宿信息（街道/小区级）。 | **C2/C3** |
| **特殊敏感信息** | 不满14周岁未成年人个人信息；医疗健康记录（病史、体检报告）；宗教信仰、性取向、未公开的违法犯罪记录。 | **C3** |

## 二、 企业/机构客户敏感数据（B端）
*企业数据一旦泄露，可能引发商业机密泄露、重大经济损失或系统性金融风险。*

| 数据子类 | 典型敏感数据项示例 | 敏感级别参考 |
| :--- | :--- | :---: |
| **企业身份与资质** | 营业执照、法人及高管身份证件、开户许可证、特殊行业经营许可证；公章、财务章、法人章的电子/物理印鉴。 | **C2/C3** |
| **企业财务与账户** | 对公账户信息、账户余额、银行流水明细；未公开的财务报表（资产负债表、利润表、现金流量表）、纳税记录、外部审计报告。 | **C2/C3** |
| **企业经营与信用** | 企业征信报告、信贷审批记录、抵/质押物明细及估值；供应链上下游核心交易数据；未公开的重大投资、并购或重组计划。 | **C2** |
| **企业鉴别与授权** | 企业网银操作员密码、U盾信息、数字证书；多级支付授权指令及审批流记录。 | **C3** |

## 三、 银行业务运营与交易敏感数据
*此类数据属于金融机构的核心业务资产，通常对应 JR/T 0197-2020 中的 4级 或 5级（重要数据）。*

| 数据子类 | 典型敏感数据项示例 |
| :--- | :--- |
| **核心账务数据** | 核心系统存款/贷款账务明细、信用卡核心账务数据、总账及分户账数据、计结息规则及底层参数。 |
| **支付清算数据** | 大额/小额支付系统报文、网联/银联清算明细、跨境收付业务信息（SWIFT报文）、法定数字货币钱包核心数据。 |
| **资管与理财数据** | 理财产品底层资产明细、信托计划数据、资金池运作数据、未公开的产品预期收益率及净值数据、自营投资交易台账。 |
| **密码与密钥数据** | 系统主密钥(MK)、工作密钥(WK)、HSM(硬件安全模块)配置参数、数字证书私钥、国密算法(SM2/SM3/SM4)的密钥材料。 |

## 四、 金融机构内部管理与系统敏感数据
*结合系统架构与运维安全，此类数据是内部威胁和外部攻击的高价值目标。*

| 数据子类 | 典型敏感数据项示例 |
| :--- | :--- |
| **员工敏感信息** | 员工身份证号、薪资薪酬数据、绩效考核结果、背景调查报告、内部通讯录及敏感岗位组织架构。 |
| **系统与网络安全** | 核心网络拓扑图、IP地址分配表、核心系统**源代码**、数据库表结构及数据字典、系统漏洞扫描报告、渗透测试报告、灾备切换预案。 |
| **运行与日志数据** | 包含明文敏感信息的业务日志、安全审计日志、数据库操作日志、特权账号（如 root, dba）的操作记录。 |
| **战略与财务数据** | 未公开的财务报告、资产负债管理(ALM)敏感指标、重大战略规划、高管会议纪要、未公开的采购合同及供应商报价。 |

## 五、 监管报送与合规敏感数据
*此类数据具有强监管属性，篡改或泄露将面临严厉的监管处罚。*

| 数据子类 | 典型敏感数据项示例 |
| :--- | :--- |
| **反洗钱(AML)** | 大额交易报告、可疑交易报告(STR)、客户洗钱风险等级划分结果、国际制裁名单匹配及拦截记录。 |
| **征信与报送** | 向人行征信中心报送的个人/企业信贷明细及违约记录；EAST系统明细数据、1104报表底层明细数据。 |
| **消保与合规** | 客户投诉明细及纠纷调解记录、监管现场检查底稿、监管处罚决定书及内部整改报告。 |
